# 02 — Art Direction

**Metaphor:** Toàn bộ game là **gia phả / địa đồ mực trên giấy tuyên**.  
Đồ đằng = nét cọ sống. Ban chỉ = ấn son.

---

## 1. Palette

| Role | Guide |
|------|--------|
| Paper | `#F3EBD8` |
| Aged wash | `#E2D2B0` |
| Ink | `#1A1A1A` |
| Seal | `#A31D1D` |
| Jade / linh | `#3F6B5C` |
| Danger mist | `#5C4A6E` (tím tử địa, dùng sparingly) |

Forbidden: neon, purple-indigo UI theme, flat pure white, pixel art.

---

## 2. Visual layers

1. **Paper grain** — tile texture nhẹ  
2. **Ink map** — núi, sông, đất bằng nét loang  
3. **Đằng / thụ** — silhouette rễ–thân–lá mực  
4. **UI manuscript** — khung giấy, tab mực  
5. **Seal / bloom** — motion khi ban chỉ, suy diễn, chết kiếp  

Nhân vật tộc = icon / tem mực nhỏ, không sprite ARPG.

---

## 3. Motion (3 cái lặp lại)

1. **Ink bloom** — mở panel / unlock năng lực  
2. **Seal stamp** — ban chỉ / hoàn thành mùa  
3. **Brush wipe** — chuyển mùa / đổi thế giới  

---

## 4. Solo + AI pipeline

1. Khóa palette này  
2. AI gen texture giấy + vài frame/icon  
3. Layout dựng bằng HTML/CSS hoặc Pixi UI — không ship ảnh UI nguyên tấm  
4. Font: thư pháp tiêu đề; body dễ đọc có license
