# THẦN THỤ

Bạn là **Đồ Đằng gia tộc** → **Suy diễn** qua các thế giới → thành **Thần Thụ** → ban chỉ dẫn tộc.

**Stack:** Vite + React + TypeScript + PixiJS + Zustand  
**Docs:** [Documentation/](Documentation/)

## Dev

```bash
cd d:\CV\than-thu
npm install
npm run dev
```

## Hiện có (MVP phases 1–4)

- Hub + Kỳ Suy diễn + 12 năng lực  
- Thần Thụ + Ban chỉ + 2 gia tộc địch  
- Juice: ink bloom / ấn son / brush wipe + Web Audio  
- PWA (installable khi build/`preview`)
